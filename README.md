🛠️ Autodesk Projects — Fusion 360

Welcome to my Autodesk Projects repository — a collection of 3D CAD models, assemblies, technical drawings, and design-development work created using Autodesk Fusion 360.

This repository documents my hands-on learning and projects involving 3D modeling, mechanical design, assembly, technical drawings, generative design, and shape optimization.

🚀 What This Repository Contains

🔹 3D CAD Modeling

* Mechanical components
* Individual parts
* Fasteners and hardware
* Structural components
* Custom-designed parts

🔹 Assembly Design

The repository contains multiple Fusion 360 assembly files, including:

* .f3z assembly files
* Component-based assemblies
* Recovered and revised assemblies
* Assembly drawings

🔹 Shape Optimization

One of the key areas of this repository is shape optimization, where the geometry is refined to achieve a better balance between:

* ⚖️ Weight reduction
* 💪 Structural strength
* 🧩 Functional requirements
* 🖨️ Manufacturability
* 📐 Geometric efficiency

🔹 Technical Drawings

Technical drawing PDFs are included to document:

* Dimensions
* Part geometry
* Assembly details
* Manufacturing information
* Design revisions
